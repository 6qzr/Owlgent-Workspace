# Research notes

There is one page per spike (60-minute timebox). Name the files `R1-checkpoints.md`, `R2-human-in-the-loop.md` and `R3-rag.md`.

## Template

```markdown
# RX: <topic>

**Owner:** @user · **Spike issue:** # · **Experiment:** experiments/rx_<topic>/

## Question
## Options compared
## Sources (official documentation first)
## What the experiment showed
## Recommendation
## Risks and mitigations
```

After the 10:20 share-out, the team records each decision as an ADR in `docs/adr/`.
